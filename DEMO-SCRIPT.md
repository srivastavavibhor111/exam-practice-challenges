# Demo Video Script

A suggested walkthrough for recording a 2-3 minute demo video — long
enough to show real depth, short enough that someone will actually watch
the whole thing. I can't record this for you, but I know the app's full
flow well enough to sequence it for maximum impact in a short recording.

**General advice:** record at 1080p, keep your cursor movements
deliberate (don't fidget), and consider adding text captions for the
"why this matters" beats below rather than narrating everything live —
easier to get right in editing than in one continuous take.

---

## Suggested sequence (~2-3 minutes)

**0:00–0:15 — Landing page**
Open on the landing page. Let it sit for a beat, then click "Create Your
Test." *(Caption idea: "Bring the MCQs you already have.")*

**0:15–0:40 — Create Test → paste real content**
Paste a real, recognizable block of MCQs (something like a short trivia
or general-knowledge set works well on camera — avoid anything so niche a
viewer can't follow along). Click Generate. Let the loading state show
for a moment — don't cut past it, it demonstrates real work happening,
not an instant fake transition.

**0:40–1:00 — Review screen**
Show the extracted questions. Click into one, edit the text slightly (a
small, visible edit — proves it's genuinely editable, not just a display).
If you can show a flagged warning badge on one question, even better —
briefly highlight it. Click "Create Test."

**1:00–1:15 — Test setup screen**
Show picking a duration. Brief — this is a small screen, don't linger.

**1:15–1:45 — Taking the test**
Answer 2-3 questions, showing: clicking an option, using the "Mark for
Review" button once, clicking a number in the question navigator to jump
around (demonstrates it's a real navigator, not just Next/Previous).
Optionally show a keyboard shortcut (press "2" to select option B) — a
small but memorable detail.

**1:45–2:15 — Submit → Result page**
Submit the test. Show the result page: the donut chart, the score, then
scroll to the question review section and click through a filter tab
(e.g. "Incorrect") to show the filtering actually works. If time allows,
click the bookmark icon on one question — a nice "there's more here" beat.

**2:15–2:40 — Dashboard**
Cut to the Dashboard (with pre-existing data — see note below), showing
the stat cards, performance trend, and Weak Areas section. This is the
strongest "wow, there's real depth here" moment — don't rush past it.

**2:40–2:55 — Theme toggle**
End on something visual and quick: click the theme toggle once, showing
the whole page smoothly transition to dark mode. A clean, satisfying way
to close the video.

---

## Before recording

**Seed real data first.** Complete 3-4 tests with varied scores BEFORE
recording, so the Dashboard segment shows a real trend line and Weak
Areas data instead of empty states. An empty dashboard is the single
biggest thing that would undersell this app in a demo.

**Have your example MCQ content ready in a text file**, so you're not
hunting for something to paste on camera.

**Consider two versions**: a full ~2-3 minute walkthrough for a portfolio
page, and a much shorter ~20-30 second clip (landing → create → result,
nothing else) for something like a LinkedIn post or README GIF, where
attention spans are much shorter.
